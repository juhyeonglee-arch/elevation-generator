# 모델 넘기기 전 체크리스트

입면도 자동 생성은 3dm을 그대로 읽어요. 아래만 지키면 정리 없이도 잘 나와요.

1. **입면에 안 나올 것은 레이어를 꺼 두세요.** 꺼진 레이어와 숨긴(Hide) 객체는 처음부터 '빼기'로 잡혀요. 화면의 레이어 표에서 다시 넣을 수도 있어요.
2. **일반 저장으로 저장하세요.** '작게 저장(Save Small)'은 렌더 메시를 지워서 형상을 못 읽어요. 음영 보기로 한 번 본 뒤 저장하면 확실해요.
3. **SubD는 NURBS나 메시로 바꿔 두세요** (ToNURBS). 아직 SubD는 못 읽어요.
4. **Make2D 결과 선은 그대로 둬도 돼요.** Make2D 레이어는 자동으로 빠지고, 커브·치수·글자도 무시해요.
5. **떠 있는 조각이나 작업용 사본은 지우거나 꺼 두세요.** 켜져 있으면 입면에 그대로 그려져요.
6. **레이어 이름에 재료가 있으면 자동으로 맞혀요.** 예: 유리/glass/window, 콘크리트/concrete, CLT/wood, brick, frame/beam/steel. 'Layer 03'처럼 애매한 이름은 레이어 표에서 한 번 고르면 저장돼요.
7. **북쪽이 +Y가 아니면** 화면에서 북쪽 각도(+Y에서 시계방향)를 넣어 주세요.
8. **대지·지형은 따로 레이어에 두세요.** 이름에 지형/terrain/topo/콘타/대지/site가 있으면 자동으로 '지형'이 돼요. 지형은 층·높이 계산에서 빠지고 입면에는 땅 단면선으로 그려져요.
9. **기둥 레이어 이름에 column/기둥을 넣으면** 축선(X1, X2… / Y1, Y2…)과 기둥 간격 치수가 자동으로 붙어요.
10. **단위는 상관없어요** (mm·cm·m·inch·feet 자동 변환).


## v0.8에서 추가
- **주변 건물은 따로 레이어에** 두고 이름에 주변/인접/context를 넣으면 자동으로 '주변'. 그려지지만 층 높이 계산에서 빠져요.
- **나무는 나무/수목/tree 레이어에.** 자동으로 '수목'이 돼요. 나무 마감(루버·데크·판재)은 이름에 그 말을 넣으면 목재로 봐요.
